# D-007 · Cada eureka lleva un control negativo

**Fecha:** 2026-10-07 · **Estado:** vigente

**Decisión.** E1 incluye la corrida E1a: un PRNG clásico también debe pasar M1–M5, y el informe lo declara.

**Motivo.** La batería NIST no distingue origen; sin control el jurado podría creer que pasar NIST prueba que hay entropía cuántica.

**Cómo se revertiría.** Ninguna: es una condición del criterio de éxito, no una opción.
