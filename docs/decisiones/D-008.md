# D-008 · Secretos por ruta, nunca por valor

**Fecha:** 2026-10-07 · **Estado:** vigente

**Decisión.** El token de IBM Quantum entra como ruta de fichero (ibm_token_ruta / QRECAUDA_IBM_TOKEN_FILE); no se imprime ni truncado; ningún secreto se versiona (.gitignore + trinquete por regex).

**Motivo.** Regla del entorno: los secretos viven fuera de los repos y se pasan por ruta.

**Cómo se revertiría.** Ninguna.
