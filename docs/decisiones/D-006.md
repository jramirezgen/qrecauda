# D-006 · Dos validadores independientes que se contrastan

**Fecha:** 2026-10-07 · **Estado:** vigente

**Decisión.** adaptadores/estadistica (scipy, fórmulas NIST SP 800-22) y adaptadores/nist (nistrng) implementan el mismo puerto y un contract test exige que coincidan.

**Motivo.** Un validador que nadie contrasta es una autoconfirmación; si discrepan, uno de los dos está mal y se investiga.

**Cómo se revertiría.** Quitar nistrng deja el validador propio; el contract test pasa a comparar contra valores de referencia publicados.
