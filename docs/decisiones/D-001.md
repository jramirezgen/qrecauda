# D-001 · El backend es un puerto

**Fecha:** 2026-10-07 · **Estado:** vigente

**Decisión.** El núcleo no importa ningún SDK cuántico; la fuente de bits es el puerto FuenteDeBits. Por defecto corre el simulador; el hardware IBM es un adaptador opcional (F3.04).

**Motivo.** El mensaje fundacional pide una demo sin hardware real y la estrategia pide hardware real. Con un puerto se cumplen las dos y el pitch muestra ambas.

**Cómo se revertiría.** Importar el SDK en dominio queda prohibido por C4/C5; revertir implicaría romper esos contratos, no tocar un adaptador.
