# D-004 · Extracción: Peres y Toeplitz con semilla del mismo pool

**Fecha:** 2026-10-07 · **Estado:** vigente

**Decisión.** Peres (von Neumann iterado) quita el sesgo; Toeplitz con LHL destila. La semilla de n+m−1 bits sale del mismo pool que los datos (n·(2+h) ≤ |pool|). ε=2^-64.

**Motivo.** Toeplitz necesita una semilla uniforme e independiente; una segunda fuente no está disponible en la hackatón. Declarado como hipótesis en FUNDAMENTO (Limitaciones).

**Cómo se revertiría.** Un puerto FuenteDeSemilla separada (p. ej. otro lote de hardware) sustituye el recorte del pool.
